# snn的bptt算法推导

> 记号：
> 
> `sum_i_u_t f(i)` 表示f(u) + ... + f(t)

```
U[t] = β·U[t-1] + I[t] - S[t-1]·U_th          # I[t] = S_in[t] @ W.T + b
S[t] = σ(U[t] - U_th)
```

`∂L/∂W = ∂L/∂logits * ∂logits/∂W  `

为了简单起见，我这里就让 `logits = sum_t U[t]` 了，设时间步长为T = n+1

```
∂logits/∂W = sum_t ∂U[t]/∂W
∂U[t]/∂W = ∂I[t]/∂W + ∂U[t]/∂U[t-1] * ∂U[t-1]/∂W    #得到递推式
∂U[t]/∂W = sum_i_0_t ∂U[t]/∂U[i] * ∂I[i]/∂W         #展开上式就可以得到
sum_t_0_n ∂U[t]/∂W = sum_t_0_n sum_i_0_t ∂U[t]/∂U[i] * ∂I[i]/∂W #接下来提出公因式
sum_t_0_n ∂U[t]/∂W = sum_i_0_n sum_t_i_n ∂U[t]/∂U[i] * ∂I[i]/∂W
                   = sum_i_0_n (sum_t_i_n ∂U[t]/∂U[i]) * ∂I[i]/∂W
而显然：sum_t_i_n ∂U[t]/∂U[i] = ∂logits/∂U[i]         # t < i:∂U[t]/∂U[i] = 0
sum_t_0_n ∂U[t]/∂W = sum_i_0_n ∂logits/∂U[i] * ∂I[i]/∂W
```

接下来只需要解决怎么计算 `∂logits/∂U[i]`

```
∂logits/∂U[i] = sum_t_i_n ∂U[t]/∂U[i]
              = 1 + sum_t_i+1_n ∂U[t]/∂U[i]
              = 1 + sum_t_i+1_n ∂U[t]/∂U[i+1] * ∂U[i+1]/∂U[i]
```

其中，`∂U[i+1]/∂U[i]` 显然是可以通过 `U[t] = β·U[t-1] + I[t] - S[t-1]·U_th` 算出来的，那么我们就找到了 `∂logits/∂U[i]` 与 `∂logits/∂U[i+1]` 的递推关系，使用这个递推关系，可以大大减少计算。

由此就可以得到bptt算法了。
