## 3. 检查你自己的实现

三个"抄来就能用"的对照物：

1. **替代函数的参考实现**：
   <https://spikingjelly.readthedocs.io/zh-cn/latest/tutorials/cn/surrogate.html>
   把 ATan 抄进 `surrogate_deriv`，看准确率有没有提升（实验 5）。
2. **单层 FC SNN 的完整 MNIST 例子**：
   <https://spikingjelly.readthedocs.io/zh-cn/latest/tutorials/cn/lif_fc_mnist.html>
   对照它的超参组合（T / β / 学习率 / 编码方式）和你自己调出来的。
3. **snnTorch T5**（<https://snntorch.readthedocs.io/en/latest/tutorials/tutorial_5.html>）：
   它给了"调参表"，可以拿来校准我这份文档 §5.2 的起步值。
4. **本仓库的 `check_bptt.py`**（本地，不用下载）：
   在光滑替代前向上对 `W` 做中心差分，验证 `backward` 的权重梯度因子和
   每层入口是不是对的。改写 `backward` 之后跑一遍，比看 loss 曲线可靠得多
   ——梯度偏一个数量级时 loss 照样会降（Adam 会兜住），肉眼看不出来。

### 5.2 原始格式（IDX，大端序）

```
图像文件： magic(4B) = 0x00000803 | 数量(4B) | 行数(4B)=28 | 列数(4B)=28 | uint8 像素...
标签文件： magic(4B) = 0x00000801 | 数量(4B) | uint8 标签...
```

`data_loader.py` 里就是这么解析的（magic 的低字节 = 维数）。
纯 numpy 读法：

```python
import gzip, numpy as np
buf = gzip.open("train-images-idx3-ubyte.gz", "rb").read()
x = np.frombuffer(buf, dtype=np.uint8, offset=16).reshape(-1, 28, 28)   # /255 归一化
buf = gzip.open("train-labels-idx1-ubyte.gz", "rb").read()
y = np.frombuffer(buf, dtype=np.uint8, offset=8)
```

### 5.3 万一要重新下载

旧地址（`yann.lecun.com`）经常挂；实际可用的：
