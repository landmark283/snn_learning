## 1. 第一步：把连续输入变成脉冲（编码）

SNN 的输入必须是 0/1 脉冲，但图像是 0~255 灰度。所以要"编码"。

### 1.1 Rate coding（速率编码）—— 99% 的入门代码用它

把像素值当概率：

```
p_i = x_i                  # x_i ∈ [0,1]
S_i(t) ~ Bernoulli(p_i),   t = 0 .. T-1
```

于是 `T` 步内脉冲数 / T ≈ `x_i`，是**无偏估计**（噪声标准差 ≈ `sqrt(x_i(1-x_i)/T)`）。
这正是练习 1 要实现的，验收标准 `T=100` 时 `MAE < 0.03`。

**实测**（`verify_setup.py` 会复现，256 个样本）：

| T | 5 | 10 | 25 | 100 |
| --- | --- | --- | --- | --- |
| MAE | 0.0169 | 0.0121 | 0.0079 | 0.0040 |

注意这个 MAE 比 `sqrt(x(1-x)/T)` 的典型值小得多——因为 MNIST 大部分像素是**纯黑（x=0）**，
它们必然不发脉冲、误差恒为 0，把平均值拉低了（整体脉冲占比只有 12.8%）。
看"有内容的像素"的误差才接近理论值。

| 变体 | 做法 | 特点 |
| --- | --- | --- |
| Bernoulli | `rand < x` | 随机，训练时等于数据增强，常用 |
| 相位累加（确定性） | `arange(1,T+1)/T <= x` | 无随机，调试时更可复现；脉冲数 = floor/ceil(x·T)，误差必然 < 1 |
| 泊松编码 | 用泊松过程的时间间隔 | 更"神经科学"，实现更麻烦 |

**T 怎么选**：T 越大编码越准，但计算量线性增长（BPTT 也是线性）。
入门用 `T=10~25`；追求精度/低延迟的论文会把 T 压到 4~8（这就是"低延迟 SNN"这条线的动机）。

### 1.2 Latency coding（延迟编码）

不用频率，用**发放时刻**表示强度：强的输入早发，弱的晚发。

```
t_spike(i) ∝ 1 / x_i        # 像素越亮，越早发第一个脉冲
```

- 优点：信息集中在最早的几个时间步，**T 可以很小**（低功耗、低延迟）。
- 缺点：对时序噪声敏感，训练比 rate coding 难。
- 先知道有这个东西，等主线里读到"低延迟"再回来。

### 1.3 Direct coding（直接编码）

干脆不编码，把连续值直接当第一层的输入电流 `I(t) = x`，每个时间步都一样。

- 优点：信息无损，**训练初期收敛明显更快**（梯度密，不像 Bernoulli 那样随机）。
- 缺点：严格说不再是"脉冲神经网络"的输入了（输入不是脉冲）。
- 工程上的通行做法：**前几个 epoch 用 direct，后面换成 Bernoulli**。
  练习 3 就是这么干的（`--epochs//4` 之前用 direct）。

练习 1 的验收就是搞清楚 1.1 和 1.3 的差别。

## 2. 第二步：输出怎么读出来（解码）

输出层一堆脉冲，怎么变成 10 个类别的分数？三种做法：

| 做法 | 公式 | 评价 |
| --- | --- | --- |
| **脉冲计数** | `logits = Σ_t S[t]` | 最"SNN 原味"，但计数是 0~T 的小整数，分辨率粗 |
| **膜电位读出** | `logits = mean_t U[t]` | **本项目默认**，连续、梯度多，收敛好 |
| 首次发放时间 | `-argmax_t S[t]` | 只适合延迟编码 |

**实测对比**（本仓库 `snn/` 里同一个网络、同样 3000 样本 / 8 epoch / T=10 / hidden=64）：

| 读出方式 | epoch 8 loss | epoch 8 test acc |
| --- | --- | --- |
| 累计脉冲计数 + 每步 CE | 1.29 | 54% |
| **膜电位读出 + 平均 CE** | **0.49** | **79%** |

差这么多是因为：脉冲计数用 0~25 的整数当 logits，softmax 出来的概率过于"扁平"，
而且没有发放的输出神经元 logits=0，梯度直接归零。

膜电位读出的细节（练习 3 的 `loss_and_grad`）：

```
logits = mean_t( U2[t] · (1 - S2[t-1]) )
```

`(1 - S2[t-1])` 这一项排除掉"刚刚发放、膜电位被重置"的时刻
——那些时刻的 `U` 接近 0，携带着的只是"我刚放电了"，不代表类别。

> 真实工作里两种都有：SpikingJelly 的 MNIST 例子用**膜电位按时间步平均**，
> snnTorch 的教程 3 用**输出脉冲计数 + 每步 CE**。前者更好训，后者更"纯"。

## 3. 第三步：替代梯度（核心）

### 3.1 问题

```
S = H(U - U_th)        # H 是 Heaviside 阶跃函数
dS/dU = δ(U - U_th)    # 除了一个点以外处处为 0
```

反向传播时 `dS/dU = 0` → **梯度全部归零，网络根本训不动**。

### 3.2 解法

**前向照旧用阶跃，反向换一个函数**：

```
反向时假装：  S ≈ σ(U - U_th)          # σ 是某个光滑的 S 形函数
              dS/dU ≈ σ'(U - U_th)
```

这叫 **surrogate gradient（替代梯度 / 代理梯度）**，是当前直接训练 SNN 的主流方法。
写成一句话：**"前向是脉冲，反向是假的导数"**。

### 3.3 常见替代函数

| 名称 | `σ'(x)`（x = U - U_th） | 出处 |
| --- | --- | --- |
| **Fast sigmoid** | `1 / (1 + k|x|)²` | snnTorch 默认，`k=10`（**本项目用它**） |
| Piecewise linear | `max(0, 1 - |x|/α)` | 早期工作，`α` 常取 0.5–1 |
| Exponential | `α · exp(-β|x|)` | 用得少 |
| **ATan** | `α / (2(1 + (π/2·α·x)²))` | SpikingJelly，`α=2`，实测常优于前几个 |
| Rectangular | `1/α · sign(|x| < α/2)` | 最简单，不连续 |

`k`（或 `α`）控制"反向的锐利程度"：

- `k` 太小 → 替代函数太平缓，梯度被摊薄，学得慢。
- `k` 太大 → 接近真实的 δ 函数，梯度只在一小段区间非零，**梯度消失**。

经验区间 `k ∈ [2, 100]`，入门用 10。

> **这几种函数的差别，就是 SNN 直接训练这条线上很多论文的全部内容。**
> 主线第 3 节里的 `DSpike`、`SML`（自适应/可学习的替代函数）
> 都是在这个小函数上做文章。所以你在这里把 fast sigmoid 写一遍，
> 之后读那些论文时能立刻抓住它们在改什么。

### 3.4 一个更根本的视角

替代梯度的合法性可以用**"平滑化"**来理解：把阶跃函数用一个光滑函数
在极限意义下逼近，就得到一个处处可导的代理网络。用这个代理网络算梯度，
再去更新原网络的参数。这也是"隐式微分 / 平衡态"那条路（`2109.14247`）的出发点
——它们换的是"怎么求梯度"，不是"网络长什么样"。

## 4. 第四步：BPTT（沿时间反向传播）

### 4.1 前向

一层 + 一个时间步（`B` 个样本）：

```
I[t]   = S_in[t] @ W.T + b                             # (B, N_out)
U[t]   = β · U[t-1] + I[t] - S[t-1] · U_th             # 有状态！
S[t]   = (U[t] >= U_th)
```

把 `T` 步串起来就是一张**展开的深网络**（深度 = T）。反向传播要穿过这 T 层。

### 4.2 反向（务必手推一遍）

记 `g_in[t] = dL/dU[t]`（来自上层的反向），从 `t = T-1` 倒着走：

```
1) dS[t]     = ( g_in[t] + g ) · surrogate'( U[t] - U_th )
2) dW       += dS[t].T @ S_in[t]
3) db       += dS[t].sum(axis=0)                # 沿 batch 求和
4) dS_in[t]  = dS[t] @ W
5) g         = ( g_in[t] + g ) · β  -  dS[t] · U_th
```

第 5 行是整个 BPTT 的**灵魂**，它同时有两项：

| 项 | 来源 | 含义 |
| --- | --- | --- |
| `(g_in[t] + g) · β` | `U[t]` 对 `U[t-1]` 的偏导 | 膜电位通过泄漏传到上一步 |
| `- dS[t] · U_th` | `U[t]` 对 `S[t-1]` 的偏导 | **重置**也参与反向传播 |

漏掉第二项，梯度就是错的（网络还是能学，但会差几个点，而且 β 大时更明显）。

> **进阶**：严格来说 `S[t-1]` 本身也依赖 `U[t-1]`，所以还应该多一项
> `- U_th · surrogate'(U[t-1] - U_th) · g`。标准替代梯度法**忽略**了它。
> 补上这一项的工作就是 EventProp / 事件驱动精确梯度那条线
> （`resources` 里那篇 *Event-Based Backpropagation can compute Exact Gradients
> for Spiking Neural Networks*）。入门阶段先按标准做法写，知道有这个差异就行。

### 4.3 损失函数

两种常见的（本项目用第一种）：

```
(A) 每个时间步算一次 CE，取平均：  loss = mean_t  CE( logits_from_upto_t , y )
(B) 只在最后一个时间步算 CE
```

`(A)` 梯度更密、收敛更快（snnTorch 默认）；`(B)` 更省算力、更接近"最终决策"的语义。
如果你自己实现 `(B)`，会发现早期梯度很弱——这就是为什么入门推荐 `(A)`。

## 5. 第五步：训练细节（这一节全是踩过的坑）

### 5.1 层的结构（本项目）

```
S0 (T,B,784)                       ← 编码后的输入脉冲
  → Linear(784→H) → LIF → S1
  → Linear(H→10)  → LIF → 读出膜电位 U2
```

**输出层要不要发放？**
不发（膜电位读出，见 §2）更稳；发（脉冲计数）更"纯"但更难训。
入门选前者，等准确率上去了再回头试后者。

### 5.2 超参起步值（本仓库实测可用）

| 超参 | 值 | 说明 |
| --- | --- | --- |
| T | 25（快跑 10） | 时间步 |
| hidden | 128（快跑 64） | 隐藏层宽度 |
| β | 0.9 | 对应 τ_m = 10 ms |
| U_th | 1.0 | 阈值 |
| 优化器 | Adam | lr = 0.02 |
| batch | 64 | |
| epochs | 20–24 | |
| 梯度裁剪 | 1.0 | **必加**，SNN 的 BPTT 容易爆 |
| 编码 | 前 1/4 epoch direct，之后 Bernoulli | 见 §1.3 |

**CPU 速度参考**（Python 3.14 + numpy，本机）：
60000 样本 × T=25 × hidden=128 ≈ **25 秒 / epoch**。24 个 epoch 约 10 分钟。
`--n 10000 --T 10 --hidden 64` 时只要 **1 秒 / epoch**（调参阶段用这个）。

### 5.3 权重初始化

He：`W ~ N(0, sqrt(2/N_in))`，和 ReLU 网络一个道理。
**SNN 对初始化比对 ANN 敏感得多**：初始化尺度偏大 → 全体饱和（发放率 ~100%）；
偏小 → 全体死掉（发放率 ~0%）。所以 §6 的发放率诊断是必须做的。

### 5.4 BN 在 SNN 里为什么不一样

普通 BN 会破坏脉冲的稀疏性和时序结构，所以 SNN 用 **TDBN**
（Threshold-Dependent Batch Normalization，`2011.05280`）：
在时间维+通道维一起归一化，并把归一化后的数据按阈值缩放。

**这就是主线第 2、3 节里 `TDBN` 的位置**——你现在写的 `beta`/`W` 手工调参，
它就是来把这个调参自动化掉的。

## 6. 诊断：训练不动时按这个顺序查

| 症状 | 先看什么 | 常见原因 |
| --- | --- | --- |
| loss 完全不降 | **隐藏层发放率** | 0% → 神经元死了（权重太小 / 阈值太高）；≈100% → 全饱和 |
| loss 变 NaN | 梯度范数 | 没裁剪；T 太大；lr 太大 |
| 准确率卡在 10% 左右 | 读出层 | logits 用了脉冲计数且几乎全 0；标签没 one-hot |
| 准确率卡在 50–70% | 编码 + T | T 太小；编码 MAE 太大；隐藏层宽度不够 |
| 训练好但测试差 | 过拟合 | 常规 ANN 的处理方式一样适用 |
| 形状报错 | 打印形状 | `(T, B, N)` 三个轴搞混——SNN 里 90% 的 bug |

**发放率怎么算**：`S1.mean()`。健康区间大约是 **5% ~ 50%**。
本文档的参考实现跑到收敛时隐藏层发放率 ≈ 32%。

**数值梯度校验（强烈建议做一次）**：
用中心差分检查 `surrogate_deriv` 和 `LIFLayer.backward` 的手写梯度：

```
(f(x + h) - f(x - h)) / (2h)   vs   f'(x)
```

注意：**只能校验求导部分，不能校验整个 SNN**——因为阶跃函数的真实导数是 0，
数值梯度会得到 0，而代理梯度不是 0。所以校验方式是：
把 `S = (U >= U_th)` 临时换成 `S = surrogate(U - U_th)`（前向也用光滑函数），
这时网络处处可导，数值梯度和解析梯度应该吻合到 `1e-4` 量级。
**这一步能省掉你后面几小时的玄学调试。**

## 7. 一句话总结这一份

```
输入 → [编码] → 脉冲 → [Linear + LIF] × N → [读出]
反向：前向用阶跃，反向用替代导数，沿时间 BPTT 传回去
```

想加深，只需要分别加强这三个方括号里的东西：

| 方括号 | 加强方向 | 对应主线 |
| --- | --- | --- |
| 编码 | 低延迟编码、学习式编码 | 第 4 节（异步/低延迟） |
| LIF 层 | 更好的替代梯度、TDBN、更深的残差结构 | 第 3 节（DSpike / SML / TDBN / ResNet） |
| 读出 | 时序投票、多时间步损失 | 第 2 节（ANN→SNN 转换的误差分析） |
