## 3. 两个核心问题（整个入门就围绕这两个）

**问题一：连续输入怎么变成离散脉冲？**
→ 靠"膜电位累积到阈值就发放、然后重置"。这就是 `01` / `02` 做的事。
关键词：时间常数 τ、衰减系数 β、阈值、重置、不应期。

**问题二：脉冲不可导，怎么训练？**
→ 前向保留阶跃函数，**反向换一条光滑曲线的导数**（替代梯度），
然后沿时间轴反向传播（BPTT）。这就是 `03` 做的事。

这两个问题答上来，SNN 入门就算过了。剩下的都是它们的变体。

## 4. 卡住的时候

1. 先看 `reference_solution.py` 里对应那一段的实现（对照着看，别直接抄）。
2. 形状不对就打印形状：SNN 的 90% 的 bug 是 `(T, B, N)` 三个轴搞混。
3. 训练不收敛，按这个顺序查（详见 `02_脉冲层与训练.md` §6）：
   - 隐藏层发放率是不是 0%（神经元死了）或接近 100%（全饱和）？
   - 输入编码的 `MAE` 大不大（编码就错了，后面全错）？
   - 梯度是不是没有裁剪，`loss` 直接 NaN？
   - `T` 太小（< 10）时，脉冲计数的分辨率不够。
4. 还是不懂，直接把报错/公式拿来问。
